# Slide Story Architect：AI PPT 大纲与演示叙事规划 Skill

大多数演示文稿的问题不是“不够好看”，而是每页都在放资料，却没有一条能让观众跟下去的逻辑线。

`slide-story-architect` 是一个面向工作汇报、商业路演、课程和提案的开源 AI PPT 大纲与演示叙事 Agent Skill。它先确定观众和决策，再生成故事线、逐页结论式标题、证据、视觉形式和讲者过渡。兼容 Codex、Claude Code、Cursor 和 OpenCode 等支持 `SKILL.md` 的工具。

## 使用示例

```text
用 $slide-story-architect 把这份调研材料整理成 12 页管理层汇报。
观众要决定是否投入下一阶段预算，每页只承担一个任务。
```

## 你会得到

- 一句话演示目标
- 开场、张力、证据、方案和行动的叙事线
- 每页标题、核心结论、证据和视觉建议
- 可删除内容和附录建议
- 讲者备注中的过渡句

## 安装

```bash
cp -R skills/slide-story-architect ~/.codex/skills/
```

## 适用场景

- 工作汇报、管理层汇报和项目复盘 PPT 大纲
- 创业路演、销售提案和预算申请的故事线
- 研究报告、课程和培训材料转幻灯片结构
- 精简页数、修改标题和重组现有 PPT 逻辑
- 为每页选择图表、流程图、截图或对比表

## 常见问题

### 它会直接生成 PPTX 文件吗？

这个 Skill 专注演示目标、叙事结构和逐页内容规格。只有实际连接幻灯片生成工具并验证文件后，才能声称已生成 PPTX。

### 和普通 PPT 大纲有什么区别？

它要求每页只承担一个工作，且所有标题连读后能复述完整故事；重要结论必须有证据或明确标为假设。

### 长文档会按段落拆页吗？

不会机械拆页。它会围绕观众需要做出的理解和决定重新组织内容，多余材料放入附录。
